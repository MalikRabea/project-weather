🔹 Title: Weather Forecast App
📄 Description:
A responsive weather forecasting application built with React and Axios, allowing users to search for real-time weather data by city name. The app fetches data from a public weather API and displays current conditions including temperature, humidity, and sky status.

🚀 Live Demo:
https://quiet-marigold-1df66d.netlify.app

🧰 Technologies Used:
React.js (Functional Components + Hooks)

Axios (for API integration)

OpenWeatherMap API (or any weather API you used)

Bootstrap (for responsive design)

Netlify (for hosting)

📸 Features:
Real-time weather data by city

Dynamic icon and status rendering

Responsive layout for desktop and mobile

Clean, minimalistic user interface
